# Backend
## Instalar dependencias
Para inicializar el backend se ejecuta el comando:

```
npm init
```

Luego de esto el ejecutable nos hara preguntas, y diligenciamos lo respectivo para luego instalar las dependencias de desarrolllo.

```
npm install cors multer express mysql2
```

# Frontend
## Crear un proyecto de REACT + Vite como plantilla

Para crear un proyecto de React + Vite y que funcione a la primera se debe ejecutar el siguiente comando:

```
npm create vite@latest frontend -- --template react
```

Debe de tener en cuenta que el nombre frontend es el nombre de la carpeta en este caso contiene el proyecto REACT
